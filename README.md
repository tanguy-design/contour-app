# Contour

**Design tools that take perception seriously.**

Contour is a small suite of tools for the parts of design where what you see outruns what you compute. It begins with color: the palette tool takes the colors you already have and builds each into a complete, readable scale, honest about how every shade will be seen. A type scale tool is next.

## Tools

Contour is growing into a small suite of perception-first design tools.

| Tool | What it does | |
| --- | --- | --- |
| **Palette** | Builds complete, readable OKLCH scales from the colors you already have: perceptual families, honest readability tiers, a dark mode built rather than inverted, and sourced suggestions. Colors come in as text in any format, from the OS picker, or read out of an image. | [Read more](./palette.md) |
| **Type scale** | Planned. | |

Nothing to install for users; Contour runs in the browser. It is built for keyboard, screen reader, and forced-colors use, with a visible focus ring and reduced-motion support. The interface is English today. A French translation is written and lives in the app, waiting on a review pass before the language picker is turned on. It is made for landscape tablets and desktops: below 960 pixels of width it steps aside with a note, and saved work waits for a wider window.
